# LinkedIn posts

One LinkedIn post per blog post. Post each one the same day its blog post goes live.

**How to use**
1. Copy the text under "Post" into LinkedIn.
2. LinkedIn tends to show posts with outside links to fewer people, so put the blog link in the **first comment** instead (the text under "First comment"). If you'd rather keep it simple, paste the link at the end of the post.
3. Reply to comments in the first hour or two. That's when LinkedIn decides how widely to show a post.
