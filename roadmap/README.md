# Roadmaps

Tentative plans for what to write and what to build, October 2026 through December 2027. These aren't commitments. Move things around as news, school and life happen, and update the files when you do.

| File | What's in it |
| --- | --- |
| [content-roadmap.md](content-roadmap.md) | Every planned blog post by month: the eight already drafted, monthly anchor posts tied to known dates, project write-ups, and the rule for breaking news |
| [projects-roadmap.md](projects-roadmap.md) | GitHub projects by quarter: what each one is, the first version, stretch goals, tech, the blog posts it feeds, and risks |

**The thesis everything connects to:**
AI agents turn every input into a potential instruction, so security has to shift from protecting data to governing what software is allowed to do. That only works when business, engineering and security set those limits together, so customers stay protected and teams keep moving fast.

**Review rhythm:** look at both files at the start of each month. Mark what shipped, move what slipped, and add new ideas to the backlog sections at the bottom.
